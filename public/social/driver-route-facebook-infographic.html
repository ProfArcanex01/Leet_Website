How Drivers Create and Publish a Route on Leet

A route-first workflow built for daily commuting. Drivers create a reusable template, choose booking and publishing settings, and only go live when they are ready to take passengers.

1

Create the template

Set the route, timing, days, seat count, and route price for a commute you expect to repeat.

2

Choose trip settings

Decide whether passengers can prebook, how the trip gets published, and which payment methods you accept.

3

Add a return trip

Mirror the route for the way back so one setup can cover both legs of the commute.

4

Publish for the day

Passengers only see live trips after the route is published, which keeps what they browse accurate and current.

Route-first carpooling for drivers and passengers.
